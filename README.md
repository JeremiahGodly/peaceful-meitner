# 🚀 Desktop Home ➔ Antigravity ➔ Finder ➔ GitHub Desktop ➔ Chrome Pages (HyperFrames Video)

An ultra-smooth, colorful, 9:16 vertical motion graphics video built with **HTML5, CSS, and GSAP** conforming to **HeyGen's HyperFrames** specification.

Designed specifically for mobile phones (`1080 × 1920`, 33s) featuring an authentic **Desktop Home Screen with a macOS Floating Dock**, clicking and launching each app in realistic operating system sequence: **Antigravity AI IDE**, **macOS Finder Folders**, **GitHub Desktop**, and **Google Chrome**.

---

## 📱 Edge-to-Edge Pure Phone Screen Design

The bulky bottom player controls bar has been removed and replaced with an authentic, edge-to-edge mobile phone interface:
- **Clean Fullscreen Presentation**: No clunky player buttons, text timestamps, or bottom boxes obstructing the composition.
- **iOS Home Indicator Bar**: Centered rounded pill line at the bottom of the display.
- **Ultra-Slim Story Progress Line**: Microscopic 3.5px glowing gradient line at the bottom edge (TikTok / Instagram Reels style) tracking video progress smoothly.
- **Discreet Floating Audio Pill**: Sleek, modern `[🔊 / 🔇]` circle icon floating in the top-right corner.
- **Tap to Play / Pause**: Tapping anywhere on the screen (or pressing Spacebar) toggles Play / Pause with a subtle central indicator flash (`▶` / `❚❚`).

## 🎵 Background Music & 8-Bit Audio Experience
- **Official Soundtrack Track** (`assets/bg_music.mp3`): Plays seamlessly from the start of the video, dynamically synchronizing with play/pause, seeks, and loops.
- **Dedicated 8-Bit Retro Sound Synthesizers**:
  - `sfx8BitJump()`: Authentic square-wave rapid pitch sweep when hero leaps.
  - `sfx8BitCoin()`: Classic two-tone `B5 ➔ E6` golden coin ping when mystery block is struck.
  - Layered tactile sound effects: mechanical clicks, keypress typing clatter, air whooshes, and confetti fanfare.

## 📱 How to Preview & Watch

### Direct Browser Preview:
Open [`index.html`](file:///Users/godlyvarghese/Documents/antigravity/peaceful-meitner/index.html) in your browser:
- Pure edge-to-edge phone screen without obstructive bottom bars.
- Tap anywhere on the screen (or press Space) to Play / Pause.
- Toggle sound via the sleek floating audio pill in the top-right corner.

### Local Server:
```bash
python3 -m http.server 3000
```
Then visit **`http://localhost:3000`**.

### HyperFrames CLI:
```bash
# Live Studio Preview
npx hyperframes preview

# Render to 1080x1920 MP4 Video
npx hyperframes render --output video.mp4
```
